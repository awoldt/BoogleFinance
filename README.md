Google out of nowhere decided to redo their finance ui, and it's HORRIBLE. Made me want to vomit first time I saw it. Hated it so much that it was time someone recreated the old Google Finance UI for the people. 

The frontend is a SSR react router app, and the backend is an efficnent Golang server with proper caching to prevent too many API calls to the third-party data provider. The server code has ZERO AI code, I love writing code by hand for passion projects and I took my time building it out, learning proper Golang file sturctures, etc.
